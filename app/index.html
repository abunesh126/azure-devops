DevOps delivery demonstration

Automated Web Application Deployment on Microsoft Azure using azure,terraform and jenkins

A small, repeatable delivery pipeline that turns a Git commit into a verified Azure App Service release.

Project overview

Terraform defines the hosting infrastructure, while Jenkins packages and deploys this static site. The pipeline verifies the exact version served by the live endpoint.

Technology stack

  • Git
  • GitHub
  • Jenkins
  • Terraform
  • Azure App Service

Deployment workflow

01 · CommitPush a versioned change to GitHub.
02 · AutomateJenkins validates, packages, and deploys.
03 · VerifyThe live URL is checked for the new marker.
